# Portafolio profesional | Ricardo Jaraba Gallego

Sitio web personal desarrollado(Ingeniería Informática, Corporación Universitaria Lasallista).

## Descripción

Portafolio responsive que presenta mi información personal, estudios, proyectos, lenguajes de programación y áreas de interés profesional.

## Secciones

- Información personal
- Estudios realizados
- Proyectos
- Lenguajes de programación
- Áreas de interés profesional
- Contacto

## Tecnologías usadas

- HTML5
- CSS3
- Bootstrap 5.3 (framework responsive)
- Google Fonts (Bricolage Grotesque, Source Sans 3, JetBrains Mono)

## Diseño responsive

El sitio se adapta a pantallas pequeñas (celular), medianas (tablet) y grandes (escritorio) usando el sistema de cuadrícula y la barra de navegación colapsable de Bootstrap.

## Cómo ejecutarlo localmente


1. Clona el repositorio:# perfil-profesional

2. Abre el archivo `index.html` en tu navegador.

No requiere instalación ni dependencias: Bootstrap se carga desde un CDN.
